# adbfit
adb fit strava scripts 

Instructions: 
On Monday, save the Strava leaderboard pages locally. Make sure you choose the LAST WEEK tab. 
Either save the file by  appending  _mmmDD to the filename. example : 
"San Jose, California Club _ Almaden Fit - Season 7 (Group 2 - Evens) on Strava_Feb23.html"

If you have multiple strava groups save them similarly, all with the **_mmmDD** extension. 

Run the strava updater script locally in the same directory. Pass in **mmmDD** as command line argument. The same one with the file names. 
Upload output file example: "Almaden Fit - Season 7_output_Feb23.csv" to the master tracking sheet as a NEW sheet. Name the sheet **mmmDD**.
Change all column formats to plain text. 

That should be it for the strava part.
